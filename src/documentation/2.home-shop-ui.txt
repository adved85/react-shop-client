		❗If you see this Error code on the screen
❌ [plugin:vite:import-analysis] Failed to resolve import "bootstrap/dist/css/bootstrap.min.css" from "src/main.jsx". Does the file exist?

		It means package names were added to package.json but not installed yet
		❎🚑 You need to install them inside from "vite_react_dev" container
			"bootstrap": "^5.3.8",
			 ---
			"react-bootstrap": "^2.10.10",


		Enter to container:
			docker exec -it vite_react_dev sh

		Then install them (and show both - (1) normal output + (2) error output)
			npm install 2>&1
