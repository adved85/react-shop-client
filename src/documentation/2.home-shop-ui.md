## Styles — react-bootstrap

To add more styles for our new pages, we need a css framework or library. Let's install the react-bootstrap package.

Open a second terminal and enter the frontend shell:

```sh
docker compose run --rm frontend sh
```

Installation:

```sh
npm install react-bootstrap bootstrap
```

Docs of the packages:
- react-bootstrap 2.10.10 — https://react-bootstrap.github.io/docs/getting-started/introduction
- bootstrap 5.3.8 — https://getbootstrap.com/docs/5.0/utilities/shadows/

**main.jsx** — add bootstrap styles:

```js
import 'bootstrap/dist/css/bootstrap.min.css'
```

### ❗ If you see this error on the screen

```
❌ [plugin:vite:import-analysis] Failed to resolve import "bootstrap/dist/css/bootstrap.min.css" from "src/main.jsx". Does the file exist?
```

It means the package names were added to `package.json` but not installed yet.
❎🚑 You need to install them inside the `vite_react_dev` container:

```json
"bootstrap": "^5.3.8",
"react-bootstrap": "^2.10.10",
```

Enter the container:

```sh
docker exec -it vite_react_dev sh
```

Then install them (and show both — (1) normal output + (2) error output):

```sh
npm install 2>&1
```

> Why this happens — `docker compose run --rm` installs into a throwaway container — is explained in [guide 6](6.testing-and-lint.md), Step 1.

## Sass styles

Now create `css` inside `assets`, next to the `/images` folder, and add `styles.scss` to that folder:

```
/src/assets/css/ + styles.scss
```

Now copy the content of `src/assets/images/snippets.txt` to `src/assets/css/styles.scss`. You will see there:

```scss
@import DM+Sans from fonts.googleapis.com/
$primary-font
$primary-white
```

And import `styles.scss` into `main.jsx`.

### ❗ Next you should see this error

```
❌ [plugin:vite:css] Preprocessor dependency "sass-embedded" not found. Did you install it? Try `npm install -D sass-embedded`.
```

```sh
docker compose run --rm frontend sh
npm install -D sass-embedded
```

So again, enter the `vite_react_dev` container and install the package (`"sass-embedded": "^1.100.0"`):

```sh
docker exec -it vite_react_dev sh
npm install -D sass-embedded
```

**NOW your home page should open correctly** — with a black header and the centered text "Your Fashion Partner".
