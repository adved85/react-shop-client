## Unlock files/folders 💫

Since all files/folders are locked (access is allowed only to root), this command will unlock the resource for the user named "home".

```sh
$ sudo chown -R home:home /home/home/containerized/react-shop-client/
```

OR

```sh
home@laravuy:~/containerized$ sudo chown -R home:home react-shop-client/
```

## Install packages

ok, app was successfully installed and running!
Now let's install some extra packages — `react-router-dom`, `react-hook-form` (useForm) and `react-toastify`.

Enter the frontend shell:

```sh
docker compose run --rm frontend sh
```

Install router-dom:

```sh
npm i react-router-dom
```

Install useForm:

```sh
npm install react-hook-form
```

Install toast:

```sh
npm i react-toastify
```

### Docs of installed packages

- https://reactrouter.com/
- https://www.react-hook-form.com/get-started/
- https://fkhadra.github.io/react-toastify/introduction/

## Start and stop the app

Now, to start and stop our client app, we have to start/stop docker compose from the root folder (`react-shop-client`).

```sh
docker compose up
docker compose down
```

> ❗ **Added later:** the Node version is no longer hardcoded in `docker-compose.yml`. It reads `image: node:${NODE_VERSION}` from the `.env` file at the project root (`NODE_VERSION="25-alpine"`), which is the same single source the Dockerfile and CI use — see [guide 7](7.docker-ci-and-releases.md), Step 4.
